# Билим AI — фронт-макет (Next.js)

Демо ИИ-платформы для ОшМПУ по ТЗ: студент проходит тему «Матрицы» в три шага (знакомство → практика → миссия), преподаватель видит карту понимания и ставит оценку. Бэкенда нет — всё на mock-роутах Next.js.

## Запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

`/` — лендинг, `/student` — путь студента, `/teacher` — кабинет преподавателя.

## Стек

Next.js 15 (App Router) · TypeScript · Tailwind v4 · TanStack Query (запросы) · Zustand + persist (прогресс, XP, ошибки, язык) · lucide-react. UI-кит свой (`components/ui.tsx`), без shadcn — меньше зависимостей.

## Что сделано

- **Знакомство** — чат с ИИ: крючок по интересам → «главная задача» (сам ИИ на матрицах) → карта 12 применений → обещание миссии. ИИ отдаёт JSON-виджеты (`matrix`, `apps`, `missions`, `cta`), фронт рисует интерактивную модель с анимацией.
- **Практика** — задачи по лестнице сложности, проверка кодом, подсказки вопросами, детект ошибки «A·B vs B·A» → кнопка «задача на эту ошибку». Ошибки копятся в «Мои пробелы».
- **Миссии** — 12 штук; 3 интерактивные: корабль на матрицах (4 уровня), фильтр для фото (свёртка 3×3), мини-нейросеть (W·x, 5×5). Остальные — «лаборатория» (чат + калькулятор).
- **Преподаватель** — статы, активность, типичные ошибки, шаги, тепловая карта студент × понятие, миссии на проверку (черновая оценка ИИ + итог), экспорт CSV для Excel. Миссия, сданная в демо-студенте, сразу появляется здесь.
- **Оболочка урока** — дерево курса (модули → уроки → шаги), хлебные крошки, «Назад / Далее», прогресс урока и курса.
- **Три уровня объяснения** — под ответом ИИ кнопки «🐣 Проще / 🎓 Строже».
- **Научи ИИ** — ИИ-школьник Айбек задаёт наивные вопросы, отмечает 4 ключевые идеи, в конце разбор с оценкой (метод Фейнмана).
- **Фото из тетради** — в практике «Сфоткай решение»: ИИ находит шаг с ошибкой и задаёт вопрос (в mock — разбор заготовленного решения).
- **Копилот преподавателя** — контрольная в 2–3 варианта с учётом ошибок группы, ответы проверены кодом, печать.
- **Живая карта понимания** — строка демо-студента в тепловой карте считается из его реальных действий.
- РУ/КЫ переключатель (интерфейс; mock-ИИ понимает «эмне үчүн…»), кнопка «Сбросить демо» для повторных прогонов.

## ИИ: mock → live

- `AI_MODE=mock` (по умолчанию) — ответы из `lib/ai/mock.ts`, ключ не нужен.
- `AI_MODE=live` + `ANTHROPIC_API_KEY` в `.env.local` — реальный Claude через `lib/ai/index.ts` (при ошибке откат на mock). Ключ только на сервере, в браузер не попадает.

## Переход на бэкенд (ASP.NET Core)

Все запросы идут через `lib/api.ts`. Поставь `NEXT_PUBLIC_API_URL` и реализуй на бэке те же контракты:

| Метод | Путь | Тело / ответ |
|---|---|---|
| POST | `/api/chat` | `ChatRequest` → `AiReply` |
| GET | `/api/tasks?solved=&focus=` | → `Task` |
| POST | `/api/tasks` | `{ task, answer }` → `CheckResult` |
| GET | `/api/missions` | → `Mission[]` |
| GET | `/api/teacher` | → `TeacherData` |

Типы — в `lib/types.ts` и `lib/tasks.ts`.
